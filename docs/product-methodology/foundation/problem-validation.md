# 문제 검증 (Problem Validation)
> 유형: foundation · 2026-07-21 · 갱신 2026-07-30(무신사 프레임 재정립) · 방법: 5Why + 웹 리서치(실제 목소리) + 직접관찰

## 5Why (왜 못 찾나)
1. 왜 못 찾나? → 원하는 "백프린팅만 노란 + 기능성 + 내 사이즈" 티가 검색·필터로 안 걸림
2. 왜 안 걸리나? → 검색이 색을 **옷 전체**로만 인식, "프린팅색=노랑/바탕=흰" **조합**을 표현할 수단이 없음
3. 왜 조합이 안 되나? → 상품 데이터가 색·프린팅위치·소재·기능성 같은 **구조화된 속성**으로 존재하지 않음(제목·이미지에 파묻힘)
4. 왜 확인이 오래 걸리나? → 검색결과가 **대표 썸네일 1장**뿐 → 등판·소재·사이즈를 상품마다 상세페이지 들어가 확인
5. **근본 원인**: 상품이 "말로 조합해 검색할 수 있는 속성 데이터"로 구조화돼 있지 않고, 검색이 키워드 매칭에 머무름. → **속성 구조화 + 시맨틱(말로) 검색**이 해법.

## 5Why 재정립 — 무신사 프레임 (2026-07-30)
> 데이터 소스가 무신사로 전환(README D14)되면서 문제 무대를 "포털 검색 전반"에서 "무신사 내 발견"으로 좁혀 재정립. 위 원본 5Why는 히스토리로 유지.

1. 왜 무신사에서 못 찾나? → "흰 바탕 + 노란 백프린팅" 티가 검색·필터로 안 걸림
2. 왜? 44색 필터까지 있는데? → 색 필터는 **상품 대표색 1개** 기준. 바탕색/프린팅색을 구분하는 축이 없고, 프린팅 위치(앞/뒤) 필터도 없음
3. 왜 그런 축이 없나? → 상품 속성이 **파는 사람 기준**(브랜드·카테고리·대표색)으로 구조화돼 있고, **찾는 사람의 언어**(바탕×프린팅색×위치 조합)로는 구조화돼 있지 않음
4. 왜 검색어로도 안 되나? → 검색이 상품명·브랜드 키워드 매칭 중심이라 "백프린팅만 노란" 같은 조합 질의를 속성으로 해석하지 못함
5. **근본 원인(재정의)**: 구조화가 "없어서"가 아니라 **구조화의 축이 사용자의 탐색 언어와 어긋나 있어서**. 상품·필터가 다 갖춰진 국내 최대 패션 플랫폼에서도 '보이는 것'(바탕색·프린팅색·위치·그래픽)의 축으로는 발견이 안 된다. → 해법은 동일하게 속성 태깅 + 말로 하는 조합 검색이되, 포지셔닝은 **"무신사 위에 발견 레이어를 얹는다"**로 선명해짐.

- **무신사 내 우회행동**(스냅 뒤지기·리뷰 사진 뒤지기·브랜드샵 순회): **추측(플래그)** — 사용자 인터뷰·웹 리서치로 보강 대상.

> **이 5Why에는 종목이 안 걸려 있다.** 근본 원인(구조화의 축 ≠ 탐색 언어)은 클라이밍이든 러닝이든 동일하게 성립하므로, 2026-07-30 세그먼트 조정(D15: 클라이머 → 장비색 코디하는 운동인)에도 **문제 정의는 바뀌지 않는다.** 바뀐 것은 누구부터 만나느냐뿐.
