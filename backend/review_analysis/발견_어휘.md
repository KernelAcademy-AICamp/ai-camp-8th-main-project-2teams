# 발견 어휘 (누적) — 리뷰에서 새로 발견된 표현·속성

리뷰 태깅을 돌리며 발견되는 (1) 기존 태그의 새 표현(alias), (2) 미등록 속성(새 태그 후보)을 누적 기록한다.
alias는 `1단_추출_프롬프트.md`/`tag_rules`에 반영해 다음 배치부터 자동 인식한다. 새 태그 후보는 팀이 승격 결정(사전 §8).

## alias (기존 태그의 새 표현) — 발견 즉시 프롬프트 반영
| 발견 표현 | → 기존 태그 | 발견 배치 |
|---|---|---|
| 속건성 / 드라이핏(건조 빠름) / 땀 배출 잘됨 | 흡습속건 | 배치2 |
| 부들부들 / 보들보들 | 부드러움 | 배치2 |
| 쫀쫀하다 | 신축성좋음 | 배치2 |
| 짱짱하다 | 탄탄함 | 배치2 |
| 상표·택 꺼끌거림(까끌거림) | 택따가움 | 배치2 |
| 시원하다 / 청량하다 | 냉감 | 배치2 |
| 어깨 넓은 거 티 안 남 | 체형보정 | 배치2 |
| 딱 생각한 색 | 화면색상일치 | 배치2 |
| 고급스럽다 | 재질좋음 | 배치2 |
| 팔랑거리지 않음 | **탄탄함** | 배치2 |
| 안 덥다 / 안 더움 | **냉감** | 배치2 |
| 쨍하다 / 쨍한 / 쨍하니(색) | 선명한발색 | 배치3 |
| 톡톡한(재질/원단) | 도톰함 | 배치3 |
| 통기성 좋음 | 통풍 | 배치3 |
| 걸리적거리지 않음 / 무브 편함 / 벽 탈 때 안 걸림 | 활동성좋음 | 배치3 |
| 부유방 커버 / 말라보임 / 몸매 잡아줌 | 체형보정 | 배치3 |
| 만듬새 좋음 / 꼼꼼한 바느질 | 마감깔끔 | 배치3 |

> 팀 결정(2026-07-24): **시스루**는 `비침있음`으로 합치지 않고 **독립 태그**로 채택(스타일 축, 의도된 비침/메시). 단 "얇아서 시스루로 비친다"류는 문맥상 **얇음**으로 판단(키워드 아닌 문장 전체 판정). **안 덥다 → 냉감**. **팔랑거리지 않음 → 탄탄함**. **클라이밍**은 용도 태그로 채택.

## 채택된 새 태그 (닫힌 집합 편입 완료)
| 태그 | 유형 | 뜻 | 배치 |
|---|---|---|---|
| **시스루** | 스타일 | 의도된 비치는 원단/메시. 품질 이슈 `비침있음`과 구분. "얇아서 비침"은 얇음으로 판정 | 배치2 |
| **클라이밍** | 용도 | 클라이밍/볼더링/암장/리드/멀티 용도 언급 | 배치2 |
| **초크안묻음** | 품질(클라이밍 특화) | 초크가 잘 안 묻는다/털면 떨어진다 | 배치2 |
| **각인서비스** | 안내(구매옵션) | 이니셜·이름 각인 커스텀 제공 | 배치2 |
| **피그먼트워싱** | 스타일/원단 | 피그먼트 염색·빈티지 워싱 느낌 | 배치3 |
| **옆선무봉제** | 봉제/구조 | 옆선에 박음선 없음(튜블러) | 배치3 |
| **디자인귀여움** | 취향(디자인) | 그래픽·캐릭터·프린트가 귀엽다/이쁘다. `색상예쁨`(색)과 구분되는 디자인 매력 축 | 배치4 |
| **엉덩이커버기장** | 핏(기장) | 기장이 길어 엉덩이를 덮음("엉덩이 덮는 기장/레깅스에 딱/힙 커버") | 배치4 |
| **면느낌** | 촉감/원단 | 면 같다/면처럼 부드러움/면티 느낌 | 배치4 |
| **땀안마름** | 기능(부정) | 땀이 잘 안 마름/쉽게 젖음. `흡습속건`의 반대 극성(OPPOSING 페어) | 배치4 |
| **박시핏** | 핏 | 박시하다/큼직/boxy 박스 실루엣. "박시하지 않아요" 부정은 제외(문장 판단) | 배치6·7 |
| **크루티** | 용도 | 클라이밍 크루/팀 단체 맞춤 티. 일반 단체는 `단체티·유니폼` | 배치6 |
| **홀드달라붙음** | 품질(클라이밍 부정) | 원단이 홀드/벽에 달라붙음 | 배치7 |
| **밑단말림** | 품질(부정) | 밑단/끝단이 말려 올라감 | 배치6 |

> 팀 결정(2026-07-24): 시스루·클라이밍·초크안묻음·각인서비스·피그먼트워싱·옆선무봉제 승격 완료.
> 팀 결정(2026-07-25, 배치4): **디자인귀여움·엉덩이커버기장·면느낌·땀안마름 승격** → 사전·프롬프트·`resolve` 허용 집합 편입. **가격 관련(가성비 등)은 태그화하지 않음**(검색 정보태그 성격과 결이 달라 제외 확정).

## 새 태그 후보 (미등록 속성) — 팀 승격 결정 대기
| 후보/이슈 | 유형 | 근거·빈도 | 발견 배치 |
|---|---|---|---|
| **"예뻐요/이쁩니다"(색·디자인 미지정 일반 예쁨)** | 판정정책 | 배치7 한 배치에서만 7건. 현재 규칙4(총평)로 **미부여** 중. `디자인귀여움`으로 흡수할지 / 별도 처리할지 정책 확정 필요 — **최다 이슈** | 배치6·7 |
| 드라이메쉬 / 쿨론(원단명) | 원단·기능 | "드라이메쉬 재질/쿨론티". 원단명만 언급(체감 서술 없음)이라 흡습속건·통풍·냉감 **보수적 미부여**. 원단명 alias화 여부 정책 필요 | 배치6·7 |
| 간지나다/스타일리시 | 취향(스타일) | "간지나고 좋아서/이목집중". 귀여움(`디자인귀여움`)과 결이 다른 스타일·주목도 축 | 배치7 |
| 디자인깔끔/핏예쁨/프린팅깔끔 | 취향·품질 | `마감깔끔`(봉제)·`색상예쁨`(색)과 별개인 디자인·핏·프린트 심미. 태그 부재 | 배치6·7 |
| 시인성(암장에서 잘 보임) | 용도(클라이밍) | "눈에 확 띔/잘 보임"(암장). 현재 `선명한발색`으로 근사 | 배치7 |
