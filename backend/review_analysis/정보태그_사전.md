# 정보태그 사전 — 프린팅 티 (확정 v1)

- **작성일**: 2026-07-23
- **목적**: 검색용 정보태그의 통제 어휘(controlled vocabulary). 1단 LLM 추출의 **허용 태그 목록(닫힌 집합)**.
- **범위**: 일반 프린팅 반팔티.
- **원천**: 반팔티 25개 상품·유효 1,590건 전수 정독 + 리뷰 분석 기준서.

> **⚠️ 2026-07-24 팀 결정 (이 사전에 우선 적용)**
> - **사이즈·치수·기장 태그는 최종 `review_tags`에서 전면 제외**: 4-1의 `정사이즈`·`크게나옴`·`작게나옴`·`한치수업권장`·`한치수다운권장`·`사이즈편차`·`빅사이즈대응`·`기장김`·`기장짧음`·`기장적당`·`소매김`, 그리고 `신체정보가이드`. → 3지선다 핏크기·기장 그룹 폐기. (핏 스타일 오버핏·슬림핏·루즈핏·넉넉핏, 넥라인, 체형보정, 활동성좋음은 유지)
> - **`세탁후에도그대로`(6장) = `세탁후변형없음`(4-9)로 병합**(중복 제거).
> - **추가 태그**: `클라이밍`(§5 용도), `시스루`(4-8 스타일).
> - **저장 상태**: 분석·태그 0개 → **`[]`(빈 배열)**. `{unknown}` 미사용. 미분석 = `NULL`.
> - **발견 alias 누적**: [`발견_어휘.md`](발견_어휘.md).

## 3층 구조

| 층 | 이름 | 예 | 쓰임 |
|---|---|---|---|
| L1 | 속성(aspect) | 핏·사이즈, 촉감·원단 | 그룹핑 |
| L2 | **정보태그** | `정사이즈` `비침없음` | **검색값(닫힌 집합)** |
| L3 | alias | "딱 맞아요" → `정사이즈` | 자동 부여·동의어 매칭 |

유형: **취향(방향/스타일)** = 사실만, 극성은 검색어가 결정 · **품질(±)** = 좋음/나쁨 값에 내장 · **안내** = 구매 정보 · **디자인(주관)** = 검색 변별력 약함.
